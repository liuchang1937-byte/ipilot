1. temperature 对生成分布有什么影响？
Temperature 通过把 logits 除以 T 后再做 Softmax，从而改变生成时的概率分布 [1]。T 越低，分布越尖锐，高概率 token 的优势被放大，采样更集中、更确定，适合事实问答和代码等需要稳定的场景；T 越高，分布越平坦，低概率 token 被采样的机会增加，输出更多样但随机性更高 [1][2]。它只改变采样行为，不能给模型补充知识或保证事实正确；温度为零也不等于结果一定可复现 [1]。实际不存在通用最佳温度，应基于任务评估，并通常避免同时激进调整温度、Top-K、Top-P 等参数 [1]。

2. top_p 对生成分布有什么影响？
Top-P（核采样）对生成分布的主要影响是改变采样时的候选 token 集合，而不是改变模型知识或保证事实正确[1]。它按概率从高到低累加 token 概率，选择累计概率达到阈值 p 的最小集合作为候选；集合外的低概率 token 被排除，因此候选集合大小由累计概率动态决定，而 Top-K 是固定候选数量[1]。因此，p 越小，候选集合越窄，主要保留高概率头部 token，输出更集中、更确定、多样性更低；p 越大，候选集合越大，更多低概率 token 可参与采样，输出随机性和多样性更高[1][2]。采样时会从调整后的分布中抽取 token，并可配合 Temperature、Top-K、Top-P 来影响多样性[2]。需要注意，Top-P 只改变采样行为，不能给模型补充知识或保证事实正确；不同 API 的参数范围和组合行为也可能不同[1]。

3. top_k 对生成分布有什么影响？
Top-K 会改变生成时的采样分布：它把候选 Token 限制为概率最高的 K 个，并只在这 K 个 Token 中采样；与 Top-P 按累计概率动态决定候选集合不同，Top-K 是固定候选数量[1]。因此，分布中可被采样到的 Token 集合会被截断为前 K 个，不在前 K 的 Token 不进入该次采样。它只改变采样行为，不能给模型补充知识或保证事实正确[1]；实践中常与 Temperature、Top-P 等配合，在采样中用于增加多样性[2]。
