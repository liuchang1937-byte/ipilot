1. temperature 对生成分布有什么影响？
temperature 通过缩放 logits 改变生成分布：通常将 logits 除以 T 后再做 Softmax [1]。因此 T 越低，分布越尖锐，高概率 Token 的优势被放大，采样更确定、随机性更低；T 越高，分布越平坦，低概率 Token 的相对概率上升，输出更多样，但随机性增加，可能更不稳定或更容易产生幻觉 [1][2][3]。它改变的是采样行为或分布形状，不能给模型补充知识或保证事实正确；温度为零也不等于结果一定可复现，且低温只减少随机性，不保证事实正确 [1][3]。Top-K/Top-P 等会在此基础上进一步限制候选集合，但 temperature 本身主要调节分布的尖锐或平坦程度 [1]。

2. top_p 对生成分布有什么影响？
Top-P（nucleus sampling）作用于采样分布：它按累计概率选择达到阈值 p 的最小 token 集合，并仅在该动态候选集合中采样 [1]。因此，p 越小，候选集合越小、生成分布越集中，结果通常更确定；p 越大，候选集合越大、越容易包含长尾 token，生成多样性通常更高 [1]。它与 Top-K 不同：Top-K 固定候选数量，Top-P 根据累计概率动态决定候选集合 [1]。这种调整只改变采样行为，不会给模型补充知识或保证事实正确；也不存在通用最佳值，应结合任务集评估，并通常避免同时激进调整所有参数 [1]。

3. top_k 对生成分布有什么影响？
Top-K 是解码/采样阶段作用于生成分布的参数：它不改变模型本身，只改变采样行为。使用 Top-K 时，生成不会在整个词表上采样，而是只在概率最高的 K 个 Token 中采样，因此候选集合被固定为前 K 个，概率排序在 K 名之外的 Token 不会进入采样范围。[1] K 决定候选数量：K 越小，可选 Token 越少；K 越大，可选集合越大。与 Top-P 根据累计概率动态决定候选集合不同，Top-K 固定候选数量。[1] 采样会从调整后的分布抽取 Token，Top-K 可与 Temperature、Top-P 配合使用，用于增加多样性；但不存在通用最佳值，应基于任务集评估，并通常避免同时激进调整所有参数。[1][2] 这些参数只改变采样行为，不能给模型补充知识或保证事实正确。[1]
